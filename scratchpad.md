## What This Project Is

**beads-to-linear** syncs local-first beads with Linear for org-wide
visibility. Devs keep using beads; a CI worker pushes to Linear; a
per-laptop cron pulls back. No double-entry. PMs get a live board.

See `PLAN.md` §1a for persona views, §5 for architecture, §10 for
the bead breakdown. Run `bd ready` for actionable work.
